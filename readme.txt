== Description ==

WP Super Events is a WordPress events plugin for creating, managing, and selling events from your own website. Build one-time or recurring events, accept registrations, offer free or paid tickets, connect virtual meeting tools, and display your events with responsive booking widgets.

Use WP Super Events for classes, workshops, webinars, community events, training sessions, appointments, conferences, and other in-person, online, or hybrid experiences.

= Create Events in Minutes =

Create and publish events from WordPress with an event builder designed to reduce setup time. Configure dates, recurrence, venues, hosts, ticket options, capacity, and registration details without leaving your WordPress dashboard.

= Everything You Need to Run Events =

* **One-time and recurring events** — Schedule individual events or flexible recurring sessions.
* **In-person, online, and hybrid events** — Run physical events, virtual sessions, or a combination of both.
* **Free and paid tickets** — Create multiple ticket options, control availability, and set attendee capacity.
* **Saved venues and hosts** — Reuse locations and hosts across events.
* **Event calendar and browsing** — Display events in modern list, grid, and calendar experiences.
* **Event search and filtering** — Help visitors discover relevant events.
* **Gutenberg support** — Add event experiences to WordPress pages using the block editor.
* **Stripe payments** — Accept secure payments for paid registrations.
* **Zoom integration** — Connect Zoom and create online event meeting links.
* **Google Meet and Microsoft Teams links** — Use meeting links for virtual events where configured.
* **Google Calendar and iCal support** — Help attendees add events to their calendars.
* **Attendee registration and reminders** — Manage bookings and automate attendee communications.
* **Customizable email templates** — Configure event communication templates.
* **AI-assisted event creation** — Generate event content such as descriptions and featured imagery with AI-assisted tools.
* **Analytics** — Review event, registration, revenue, and engagement information.
* **Responsive design** — Event and booking experiences are designed for desktop, tablet, and mobile.
* **Internationalization support** — The plugin includes multilingual/localized interface support.

== Installation ==

1. In WordPress, go to **Plugins > Add New**.
2. Search for **WP Super Events**.
3. Install and activate **WP Super Events – Event Booking & Tickets**.
4. Open **WP Super Events** from your WordPress dashboard.
5. Create your first event.

You can also manually upload the existing `wp-super-events.zip` package through **Plugins > Add New > Upload Plugin**.

Important: WP Super Events uses the WordPress REST API. Please ensure that `/wp-json/` is accessible. Restricting REST API access may prevent parts of the plugin from working correctly.

== Frequently Asked Questions ==

= Can I create recurring events? =

Yes. WP Super Events supports recurring event schedules so you can create repeating sessions without manually recreating each event.

= Can I sell event tickets? =

Yes. You can create free or paid ticket options, configure capacity and availability, and accept supported payments through Stripe.

= Can I run free events? =

Yes. Events can be configured with free registration as well as paid ticket options.

= Can I host online events with Zoom, Google Meet, or Microsoft Teams? =

Yes. Zoom can be connected for integrated online event setup and meeting-link creation. Google Meet and Microsoft Teams links can also be used for virtual events where configured.

= Can I run in-person, online, and hybrid events? =

Yes. WP Super Events supports in-person, virtual, and hybrid event experiences.

= Does WP Super Events work with Gutenberg? =

Yes. The plugin includes WordPress block-editor support for embedding event experiences into pages.

= What payment gateways are supported? =

Stripe is currently the supported payment gateway for paid event registrations.

= Is WP Super Events free? =

WP Super Events is available free during our 2026 launch period through December 31, 2026, with no credit card required. Paid plans are planned for 2027, and pricing will be announced before the launch period ends. Installing the plugin during the free launch period does not authorize automatic billing.

== External Services ==

WP Super Events uses ServvAI-hosted services to provide parts of its event-management, registration, integration, notification, analytics, and AI-assisted functionality. Event and account configuration required for these features may be transmitted to ServvAI services.

Optional integrations can communicate with third-party services such as Stripe, Zoom, Google services, and Microsoft services when you choose to connect those integrations. Those services have their own terms and privacy policies.

Please review the product website and applicable service documentation before enabling external integrations.
